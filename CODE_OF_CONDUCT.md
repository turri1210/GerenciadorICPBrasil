# Código de conduta

Participantes devem manter uma comunicação respeitosa, profissional e inclusiva. Assédio, discriminação, exposição de dados pessoais e ataques individuais não são aceitos.

Discussões técnicas devem se concentrar no comportamento observável do software, em evidências e em alternativas construtivas. Incidentes podem ser relatados reservadamente para `dev@yez.digital`.
