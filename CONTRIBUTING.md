# Como contribuir

1. Abra uma issue descrevendo o problema ou proposta.
2. Crie uma branch curta a partir da branch principal.
3. Não adicione binários, SDKs proprietários, certificados ou segredos.
4. Execute os testes e as auditorias de dependências.
5. Envie um pull request pequeno, explicando impacto funcional e de segurança.

Ao contribuir, você declara ter direito de disponibilizar a contribuição sob a Apache License 2.0.

Mudanças que alterem privilégios, downloads, execução de processos, criptografia, coleta de dados ou endpoints precisam de revisão de segurança explícita.
